# 🎙 ربات تلگرام تبدیل صوت/ویدیو به متن فارسی

بازنویسی کامل برنامه دسکتاپ Tkinter شما به یک **ربات تلگرام** — با همان موتور (Google Speech API v2) و همان روش پردازش «خوردخورد» (قطعه‌قطعه کردن صدا)، اما این‌بار:

| قابلیت | برنامه دسکتاپ قبلی | این ربات |
|---|---|---|
| ورودی | فایل‌های لوکال | ویس، صوت، ویدیو، پیام تصویری تلگرام |
| حداکثر حجم | محدود به رم کامپیوتر | **تا ۲ گیگابایت** (فایل چند ساعته مشکلی ندارد) |
| پردازش | قطعه‌بندی + Google API | ✅ دقیقاً همان روش + تلاش مجدد خودکار |
| تقویت صدای ضعیف | normalize با pydub | ✅ dynaudnorm با ffmpeg (معادل) |
| صف پردازش | تک‌کاربر | ✅ چند کاربر همزمان، پردازش ترتیبی با اعلام نوبت |
| لغو | بستن برنامه | ✅ دستور `/cancel` |
| خروجی | نمایش در صفحه | ✅ متن کوتاه در چت / متن طولانی فایل txt با تایم‌استمپ |
| پیشرفت | نوار پیشرفت | ✅ پیام زنده «قطعه ۴۵/۱۲۰ (۳۷٪)» با تخمین زمان مانده |

## 🔑 مرحله صفر: گرفتن کلیدها (۳ دقیقه، رایگان)

1. **API_ID و API_HASH:**
   - به [my.telegram.org](https://my.telegram.org) بروید و با شماره خودتان وارد شوید.
   - روی **API development tools** کلیک کنید → یک اپ بسازید (نام دلخواه).
   - دو مقدار `api_id` (عدد) و `api_hash` (رشته) را کپی کنید.

2. **BOT_TOKEN:**
   - در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید.
   - دستور `/newbot` → یک نام و یک یوزرنیم (باید به `bot` ختم شود) انتخاب کنید.
   - توکن شبیه `123456:ABC-DEF...` را کپی کنید.

## ☁️ روش ۱ (انتخاب شما): اجرای رایگان روی Google Colab

1. به [colab.research.google.com](https://colab.research.google.com) بروید.
2. **File → Upload notebook** → فایل `telegram-stt-bot-colab.ipynb` را آپلود کنید.
3. سلول ۱ (نصب) را اجرا کنید.

7. هر وقت خواستید لاگ را ببینید: سلول ۵. ری‌استارت: سلول ۶.

**⚠️ محدودیت‌های Colab رایگان (بر اساس مستندات ۲۰۲۶):**

## 🐳 روش ۳: اجرای دائمی رایگان روی Render + GitHub (پیشنهادی)

> ⚠️ **یادآوری مهم:** Hugging Face از ۲۰۲۶ Docker/Gradio Spaces را فقط با اشتراک PRO می‌دهد (فقط Static رایگان مانده) — پس مسیر رایگان دائمی فعلی **Render** است.

**پیش‌نیاز:** حساب رایگان GitHub و Render — هیچ‌کدام کارت بانکی نمی‌خواهند (حدود ۱۰ دقیقه):

1. **GitHub:** در `github.com` حساب بسازید → **New repository** (Private) → در صفحه رپو **«uploading an existing file»** → چهار فایل پکیج (`Dockerfile`، `bot.py`، `requirements.txt`، `README.md`) را آپلود و Commit کنید.
2. **Render:** در `render.com` با اکانت GitHub وارد شوید → **New + → Web Service** → رپو را وصل کنید.
3. تنظیمات: **Runtime: Docker** (خودش از Dockerfile می‌فهمد) | **Instance: Free** → Create.
4. **Environment → Add** سه متغیر: `API_ID`، `API_HASH`، `BOT_TOKEN` → دوباره Deploy.
5. بعد از بیلد، در تب Logs باید «✅ ربات آماده است» را ببینید → در تلگرام به بات پیام دهید.
6. **ضدخواب:** سرویس رایگان Render بعد از ~۱۵ دقیقه بی‌درخواستی خاموش می‌شود → در [cron-job.org](https://cron-job.org) پینگ هر ۵-۱۰ دقیقه به آدرس وب‌سرویس (در داشبورد Render می‌دهند) ثبت کنید. کد ربات روی پورت `PORT` که Render می‌دهد خودکار گوش می‌دهد.

**محدودیت پلن رایگان Render:** رم ۵۱۲MB و CPU ۰٫۱ هسته — بات و فایل‌های صوتی/ویس راحت بالا می‌آیند؛ فقط تبدیل ویدیوهای خیلی حجیم کندتر می‌شود.

### یا اجرا روی هر سرور Docker شخصی

```bash
docker build -t stt-bot .
docker run -d --name stt-bot \
  -e API_ID=123456 -e API_HASH=xxxx -e BOT_TOKEN=123456:xxxx \
  -v stt_session:/app/session \
  stt-bot
```

> 💡 اگر اشتراک PRO هگینگ‌فیس دارید، همه‌چیز برای HF هم آماده است: Space نوع Docker بسازید، ۳ فایل را آپلود و ۳ Secret را ست کنید — کد روی پورت ۷۸۶۰ سرور سلامت دارد و بدون تغییر کار می‌کند.

## ⚙️ تنظیمات پیشرفته (متغیر محیطی — همه اختیاری)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `CHUNK_SECONDS` | `60` | طول هر قطعه: ۳۰ / ۶۰ / ۹۰ (کوتاه‌تر = دقت بیشتر در تایم‌استمپ، درخواست‌های بیشتر) |
| `GOOGLE_API_KEY` | کلید عمومی موجود | اگر روزی کلید عمومی محدود شد، کلید خودتان را بگذارید |
| `MAX_FILE_MB` | `2000` | سقف حجم فایل ورودی |
| `GOOGLE_RETRIES` | `3` | تعداد تلاش مجدد برای هر قطعه |
| `NORMALIZE` | `1` | تقویت خودکار صدای ضعیف (۰ = خاموش) |
| `SESSION_NAME` | `stt_bot_session` | نام فایل نشست تلگرام |
| `MAX_TEXT_IN_CHAT` | `3500` | بالاتر از این طول، متن به‌صورت فایل txt ارسال می‌شود |

## 🧯 عیب‌یابی

**«HTTP 403 / 429» موقع پردازش قطعه‌ها**
کلید عمومی گوگل (که در برنامه دسکتاپ هم داشتید) غیررسمی است و گاهی محدود می‌شود. چند دقیقه صبر کنید، یا کلید مخصوص خودتان (از Google Cloud → Speech API) را در `GOOGLE_API_KEY` بگذارید. ربات خودش تا ۳ بار برای هر قطعه تلاش مجدد می‌کند.

**متن‌ها ناقص یا بخشی «خالی»**
طبیعی است: قطعه‌های سکوت «خالی» شمرده می‌شوند. اگر درصد خطا زیاد بود، صدا ضعیف است — `NORMALIZE=1` را روشن نگه دارید و `CHUNK_SECONDS=30` را امتحان کنید.

**ربات جواب نمی‌دهد بعد از مدتی (روی Colab)**
جلسه Colab قطع شده — سلول ۴ را دوباره اجرا کنید.

**«FloodWait» از تلگرام**
تلگرام موقتاً محدود کرده؛ ربات خودش صبر می‌کند و ادامه می‌دهد. فقط صبور باشید.

**فایل ۲ ساعته چقدر طول می‌کشد؟**
حدود ۱۵ تا ۳۰ دقیقه (۱۲۰ قطعه × چند ثانیه پردازش هر قطعه). پیام پیشرفت زنده دارید و می‌توانید با `/cancel` لغو کنید.

## 📌 نکات مهم

- کلید Google Speech استفاده‌شده همان **کلید عمومی و غیررسمی** برنامه دسکتاپ شماست — رایگان ولی بدون تضمین پایداری. برای استفاده حرفه‌ای، کلید رسمی Google Cloud Speech بگیرید (سقف رایگان ماهانه دارد).
- فایل‌های صوتی/تصویری فقط در حین پردازش روی سرور نگه داشته می‌شوند و بلافاصله حذف می‌شوند.
- این ربات فقط چت خصوصی را هدف گرفته است؛ اگر در گروه اضافه‌اش کنید، پیام‌های صوتی همه اعضا را پردازش می‌کند (مگر Privacy Mode را در BotFather فعال کنید).
